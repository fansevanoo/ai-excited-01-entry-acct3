An entry by @fansevanoo for ai-excited-01. A woman touches an ornate mirror in a dark, candlelit room filled with old books. The mirror does not reflect her room: it opens onto another reality of dragons, glowing crystal castles, waterfalls, purple trees, sparkling crystals, and moons.

## Run it

With Node.js 22:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ai-excited-01-output node --experimental-strip-types main.ts
```

The program creates the output directory and copies the supplied artwork byte-for-byte to `entry.png` there. Without `MAKEFUN_OUTPUT_DIR`, it writes to `/output`.
