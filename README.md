A woman in a dark, candlelit room touches a large ornate mirror opening onto a fantasy world of dragons, crystal castles, waterfalls, several moons, and purple trees. The mirror offers a luminous escape, blurring the boundary between the room and an impossible reality.

## Run it

With Node 22 (22.18 or later), run from the entry directory:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

The program creates MAKEFUN_OUTPUT_DIR and copies entry.png into it. If MAKEFUN_OUTPUT_DIR is unset, it defaults to ./out. No network is used.
